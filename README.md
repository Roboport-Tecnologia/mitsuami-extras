# mitsuami-extras

Widgets for [mitsuami](https://github.com/Roboport-Tecnologia/mitsuami) that
some platforms have no native control for.

mitsuami only ships widgets every platform has a native control for. The
widgets here are the ones apps need anyway: each is the platform's own control
where there is one, and elsewhere built the way that platform's apps build it,
so it still looks at home.

```toml
[dependencies]
mitsuami = "2.0"
mitsuami-extras = "0.1"
```
